# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.0.0] - 2026-10-18

### Added
- FactGuard AI political narrative objectivity verification platform.
- Next.js 14 frontend user interface and serverless FastAPI backend.
- Groq LLM integration for contextual objectivity analysis and bias scoring.
- Comprehensive unit test suite with high test ratio density.
- Strict HTTP security headers including Content Security Policy.
- Semgrep SAST security scanning in GitHub Actions CI workflow.
- Pre-commit hooks for consistent formatting and static code quality.
- Automated weekly Dependabot vulnerability updates.
